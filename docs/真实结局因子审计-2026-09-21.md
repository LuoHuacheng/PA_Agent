# 真实成交结局作为被预测对象：结果与功效分析

- **时间**：2026-09-21
- **工具**：`tools/outcome_factor_audit.py`（新增）
- **样本**：`trade_records/outcomes.csv` 共 102 笔成交，其中 **90 笔**可用（3 笔无 `win_r`、9 笔 `record_file` 不可读）
- **被预测对象**：`win_r`（真实风险归一化结局）—— 内含真实持仓周期与止盈止损结构
- **判定**：族级(FWER)置换零分布，每轮打乱结局、对全部 24 个特征取 max\|IC\|

## 结果：0 / 24 通过

**族级噪声门槛 \|IC\| p95 = 0.3063**（p99 = 0.3445）

| 因子 | n | IC | \|IC\|/p95 |
| --- | --- | --- | --- |
| `structure.hl_balance` | 90 | 0.2673 | 0.87 |
| `trend.ema_gap_atr` | 90 | 0.2586 | 0.84 |
| `geometry.range_atr_ratio` | 90 | 0.2397 | 0.78 |
| `trend.slope_atr` | 90 | 0.2375 | 0.78 |
| `market.dist_to_high_atr` | 90 | -0.2204 | 0.72 |
| `market.price_position` | 90 | 0.2114 | 0.69 |
| `market.dist_to_low_atr` | 90 | 0.2062 | 0.67 |
| `trend.r2` | 90 | 0.1530 | 0.50 |
| `control.close_price`（对照） | 90 | -0.1372 | 0.45 |
| 其余 15 个 | 88~90 | \|IC\| < 0.15 | < 0.40 |

**没有任何特征超出噪声。** 最强的也只是噪声门槛的 0.87 倍 —— 24 个特征里出现几个 0.2~0.27 的 \|IC\|，**正是噪声该有的样子**。

## 关键：这不是"无信号"的结论，而是"功效不足"

n=90 时，族级噪声门槛高达 **0.306**。也就是说：**即使是真效应，只要 \|IC\| < 0.30，这个检验几乎必然会漏掉。**

而在这份数据上，此前所有分析中量级最大的可信效应也就是 \|IC\| 0.1~0.15 量级（且都未通过）。**所以这次检验对"合理范围内的真效应"几乎没有检出力。**

诚实的表述是：

> **用当前 90 笔真实成交，无法判断决策时的 K 线特征能否预测交易结局。** 不是"不能"，也不是"能" —— 是**样本不够，测不出来**。

这正是我此前反复强调的：**先算噪声门槛，再看结果**。如果倒过来做，看到 `hl_balance` 0.267、`ema_gap_atr` 0.259 这种数字，很容易写成"发现了两个中等强度因子"。

## 需要多少样本

族级阈值近似 `z / √N`，24 个特征对应的 z ≈ 2.9：

| 想检出的真实 \|IC\| | 需要 N |
| --- | --- |
| 0.20 | ≈ 210 |
| 0.15 | ≈ 374 |
| 0.10 | ≈ 841 |
| 0.05 | ≈ 3364 |

当前 **102 笔 / 45 天 ≈ 2.3 笔/天**：

- 到 **N≈374**（可检出 0.15）还需约 **120 天**
- 到 **N≈841**（可检出 0.10）还需约 **320 天**

## 另外两个样本问题

1. **纪元混杂**：`era` 分布为 `''` 73 笔 / `gates-2026-09-13` 29 笔。前后是两个不同策略版本（后者加了闸门），**混在一起测等于把两个不同策略的结果池化**。分开则 n=29，更没法测。本次报告的是全部 90 笔（最大样本），但纪元混杂是一条未消除的偏差。
2. **总体为负期望**：`net_usdt` 中位 **-2.33**、均值 -1.65；win 34 / loss 65（胜率 34%）。这个样本本身就是亏损的。在一个负期望样本上找"哪些特征预测好结局"，信号会被系统性亏损噪声淹没。

## 一个值得注意（但不可当结论）的观察

真实结局与 1-bar 收益的**符号相反**：

| 因子 | 对 1-bar 收益 | 对真实结局 `win_r` |
| --- | --- | --- |
| `market.dist_to_high_atr` | **+0.05~0.11** | **-0.22** |
| `market.dist_to_low_atr` | **-0.03~-0.12** | **+0.21** |
| `market.price_position` | **-0.05~-0.11** | **+0.21** |

即：**靠近区间下沿在"下一根 bar"上不利，但在"整笔交易结局"上可能有利**。这在机制上说得通（短期反转 vs 交易周期上的均值回归入场），**但两者都在噪声带内，不能作为发现**。它只是一个**假设来源**，需要等样本足够后按预注册流程验证。

## 结论

1. **方向 1 暂时不可判定**：n=90 相对 24 个特征严重功效不足，门槛 0.306 高于合理效应范围。
2. **不是"排除"**：与方向 1 之前的那些结论（特征族/种类/horizon）不同，这次不能下否定结论，只能说**当前样本无法回答**。
3. **可执行的等待条件**：累计成交到 **≈ 400 笔**（约 4 个月）再重跑本工具，届时门槛降至 ≈0.15，才有检出力。重跑命令：`.venv/bin/python tools/outcome_factor_audit.py --rounds 500`。
4. **重跑前该先做的**：把纪元切分写进预注册（只用同一 era、或明确分层），并预先写下判定标准。

## 工具

`tools/outcome_factor_audit.py` —— 纯只读，`--era` 可切纪元，先打噪声门槛再出因子表，含 `control.close_price` 对照。**这个工具的价值在于：它会把"样本够不够"这件事排在"哪个因子强"前面。**
