## 读法（与计划第 0 节禁令 1 一致）

- **区间跨零 = 没有结论**。上表里 `禁逆势 +38.21U`（[−0.25,+2.59]）、`禁 trending_tr +31.15U`
  （[−0.46,+3.00]）、`禁做空 +30.58U`（[−0.39,+3.03]）**三个全部跨零**；
  `trade_conf>=55` 的区间 [−1.77,+0.68] 跨零且点估计为负 ⇒ 不要加置信度门槛。
- 区间**上界 < 0** 的两行（`trending_tr` [−2.85,−0.01]、`tight_channel` 全负）支持实盘已开的
  `block_trending_tr_entry=true` 方向正确。
- 唯一候选 PASS 配方见 T2（`做多 + 通道/区间`，n=14，CI [+1.01,+4.90]）。
