# 策略研究结论汇总 (2026-09-21)

> 本会话从"alphaevo 对本项目挖因子有没有帮助"开始, 最后落到一个**否定结论**.
> 本文把散落的 11 篇报告收敛成一份: 已知 / 已否决 / 未知, 并附方法论护栏 ——
> 目的是**防止重复挖同一个坑**. 细节各自链接到原报告, 不在这里重复数字.

## 0. 一句话结论

**扣掉成本后没有可复现的边际.** 四层独立证据指向同一结论(因子层无信号、出场层
0/5、走步不稳定、预注册样本外否定), 而账户上看到的巨额亏损 **99.7% 来自另一套
交易**, 不是策略本身 —— 策略自己 90 天是 **-7.18U / 1749 条腿**, 基本走平.

## 2. 已知 (可以直接引用)

1. **因子层全线无信号**: 位置/几何、趋势、通道、结构计数四类特征, 在 1-48 根
   视界、6 折走步、预注册样本外三层检验下都没有可复现信号.
2. **出场层 0/5**: `be_tp` / `be1r` / `trail05r` / `be05r` / `trail1r` 五个规则
   全部为负, Bonferroni 校正后无一显著.
3. **成本吃掉一切**: 25 个有记录日里, 手续费与毛利的比值长期在 100% 以上; 项目
   基线文档自己记录的 手续费/毛亏 = 1180%.
4. **策略 90 天基本走平**: -7.18U / 1749 条腿(阈值按 5,000U 名义上限与已分析品种
   划定的"策略可能范围").
5. **账户亏损 99.7% 是另一套交易**: 8 笔超名义上限(-2286.85U, 其中 4 笔 BTCUSDT)
   + 352 条策略外品种腿(MAGMA/COLLECT/BEAT/BOME/BCH 等).
6. **影子回放器乐观 +0.254R/笔**, 且结局判定与真实只有 53% 一致 —— 所以任何
   回放结论必须先扣这个偏差.
7. **归因覆盖率分两层**: 全部窗口 2.9%, 订单可见窗口内 **96%**. 后者才是能持续
   变好的指标; 前者主要由交易所订单只回溯约一周决定.
8. **outcomes.csv 覆盖策略损益的绝大部分**: 策略范围 -172.30U(30 天) vs
   outcomes -167.84U, 差 2.7% —— 账户口径与归因口径第一次互相印证.

## 3. 已否决 (三个伪信号 + 一个决定性控制实验)

| 伪信号 | 为什么是假的 |
| --- | --- |
| 探索集"4 个因子通过" | 阈值 0.02 **低于噪声底** 0.0467 |
| `invalidation_short` 6/6 同号 + 6/6 显著 | **绝对价位伪信号**; 探索集排名第 1 但只保留 31% |
| IC 随视界上升 | **重叠窗口伪影**(非重叠采样后消失) |

**决定性控制实验**: 把原始收盘价 `control.close_price` 当"因子"喂进同一套检验,
它在**所有视界 7/7 命中**, |IC| 从 0.113 升到 0.499 —— 证明在这份数据上, 任何
由绝对价位派生的特征都会"显著".

   订单账本覆盖不到 08-31. 已排除: 本仓库代码(无硬编码这些品种)、当前自动发现配置

## 5. 方法论护栏 (这个会话踩过的坑, 不要重蹈)

1. **先量噪声底, 再谈阈值.** 阈值低于零分布分位数时, "通过"只是噪声.
2. **零分布必须与被判样本同结构.** 把探索集的 p95 当常量去判一个更干净的新样本,
   尺子会过严 —— 正确写法是"阈值 = 被判样本自己的 family-wise p95"这条**规则**.
3. **警惕共线性.** 15m(至 09-08)与 30m(09-13 起)**零重叠**, 周期与时段/市况完全
   分不开 —— 任何"45 天回放"的跨段汇总都不可解释.
4. **警惕辛普森悖论.** "毛利 +60.63U、手续费 144.11U、亏在成本" 是跨段汇总的产物:
   15m 段毛利本就是负的, 30m 段毛利 +153.57U 而费只 31.62U. 这个汇总量两段都不描述.
5. **先算功率再解读.** 单笔 R 的 sd ≈ 1.66; 检出 +0.19R 需要 599 笔 ≈ 78 天.
   样本不够时的"不显著"是**功率不足**, 不是"没有效应".
6. **账户级 / 策略范围 / 归因覆盖窗口三层口径不可混用.** 混用会得出方向相反的结论.
   还要注意"**策略可能范围**"(逐腿判据: 未超名义上限 且 品种被分析过)与"**按品种策略
   范围**"(income 按品种过滤)是两个不同的数 —— 90 天分别是 **-1.06U** 与 **-603.67U**,
   差额来自策略品种上那几笔超标单. 评价策略用前者.
7. **模拟器先校准再用.** 本项目模拟器偏差 +0.254R/笔, 与要检验的效应同阶; 不校准
   就是自欺.
8. **预注册的阈值必须是规则而不是常量**, 且必须在看样本外之前冻结.

## 7. 建议 (非研究)

1. **不要继续在这份数据上调参.** 现有 9 天 30m 数据从原理上答不了 +0.19R 的问题;
   调参只会继续过拟合.
2. **账户纪律**: 引用任何"账户盈亏"前先跑 `account_healthcheck.py`; 评价策略只看
   "策略范围"那一行.
3. **Phase 2 / Phase 3 作废** (见 plan 文档): 因子库与成熟度清单在"无边际"结论下
   没有意义.
4. 若要继续投入, 唯一有信息量的方向是**换问题**(例如换标的/换频率/换成本结构),
   而不是在同一份 30m 数据上再挖.
