## 纪律（先写在最前面）

看验证集结果**之后**，以下任何一项都不得调整：假设、方向、阈值、样本切分、判定标准、报告层次。

一旦调整，验证集就变成新的探索集，样本外价值归零。若发现本协议有缺陷，**另开一份协议、另取一段数据**，而不是回头改这份。

## 假设 H1（可证伪）

> 在 15m 周期上，价格在近期区间中的相对位置与**下一根 bar** 的收益负相关：
> 价格越靠近区间**下沿**，下一根收益越高；越靠近上沿，下一根收益越低。

这是"单 bar 尺度短期均值回归"的一次具体操作化。**它可证伪**：若验证集上这些因子的 IC 不显著或方向相反，H1 即被否定。

## 被检验的因子与方向（事前冻结）

探索集上只有 3 个代表因子超出族级噪声门槛，全部纳入检验：

| 因子 | 探索集 IC | 事前声明的方向 `expected_direction` |
| --- | --- | --- |
| `market.dist_to_low_atr` | -0.0948 | `negative` |
| `market.invalidation_short` | -0.1446 | `negative` |
| `market.dist_to_high_atr` | +0.0713 | `positive` |

其余 14 个因子**也一并报告**，但它们**不参与 H1 的判定**（它们是探索集上未过线的因子，纳入报告只为完整性）。

## 阈值（事前冻结，不得在验证集上重标定）

探索集上的**族级**（FWER，max over 17）置换零分布，`rounds=500, seed=7`：

- `min_ic_abs = 0.06816`（族级 \|IC\| p95）
- `min_ir = 1.1063`（族级 \|IR\| p95）

**IR 不进判定**：验证集的 `(symbol, timeframe)` 组数与探索集不同，`ir_groups` 会变，IR 门槛不可比。判定**只看 \|IC\| 与方向**。

## 两层报告（事前冻结）

| 层 | 样本范围 | 定位 |
| --- | --- | --- |
| **Layer A（主判据）** | 验证集中，仅保留探索集里出现过的 `symbol×timeframe` 组合（11 个） | 严格同总体，答"同一问题是否复现" |

若 Layer A 的某个组合在验证集中缺失或样本不足，**如实报告缺失**，不得用其它组合替代、不得调整切分点。

## 判定标准（事前冻结）

对 H1 的 3 个因子，在 **Layer A** 上逐条判定：

**PASS** 的条件（三条同时满足）：
1. 观测数 `n_obs >= 30`
2. 方向一致：`IC` 与上表"事前声明的方向"同号
3. 量级达标：`|IC| >= 0.06816`

**结果分级（事前定义，避免事后解释）**：

| Layer A 通过数 | 结论 |
| --- | --- |
| 3 / 3 | **支持 H1**：该均值回归族在样本外复现 |
| 1~2 / 3 | **不确定**：不宣称成立也不否定，需更多数据（`records/` 仍在增长） |
| 0 / 3 | **否定 H1**：放弃该族，另立假设 |

**不允许**的结论方式：看到部分通过后调整阈值或方向、用 Layer B 的结果推翻 Layer A、把"方向一致但量级不足"记为通过。
