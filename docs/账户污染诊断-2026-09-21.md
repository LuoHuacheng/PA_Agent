# 账户污染诊断: 90% 的亏损是两笔违规单 (2026-09-21)

> 承接 [归因覆盖率与账户真相](./归因覆盖率与账户真相-2026-09-21.md). 那篇查明 30 天账户
> 实现 -1963.64U, 而策略范围只有 -258.89U. 本篇回答: 那多出来的钱是谁亏的.

## 1. 判据 (两条, 任一命中即标记)

单看"品种不在白名单"不够 —— 更硬的判据是**名义仓位超过配置上限**:

1. `unanalyzed_symbol` —— 该品种在 `records/pending/` 里从未出现, 即管道从没做过决策;
2. `oversized_notional` —— 单笔名义超过 `max_notional_usdt * leverage`.

配置: `max_notional_usdt = 250`, `leverage = 20` -> 上限 **5,000U**.

## 2. 结果 (`tools/account_contamination.py --days 30`)

| 分组 | 腿数 | 净额 |
| --- | --- | --- |
| 策略可能产生 | 841 | -172.30U |
| **策略不可能产生** | **76** | **-1893.57U** |
| 账户合计 | 917 | -2065.88U |

按判据: `oversized_notional` 2 条 **-1850.86U**; `unanalyzed_symbol` 75 条 -1726.63U.

**两笔超标单就占账户全部亏损的 90%**:

| 品种 | 名义 | 净额 | 判据 |
| --- | --- | --- | --- |
| HEMIUSDT | 29,369.77U | -1683.91U | 未分析 + 超标 (5.9x) |
| **BTCUSDT** | **18,127.29U** | **-166.94U** | 超标 (3.6x) |

(BTCUSDT 这笔在策略品种里, 只有名义判据能抓到 —— 它解释了早先"账户 BTC -188.26U vs
outcomes -13.84U"那个缺口的大半.)

其余按品种: SKRUSDT -24.21U / LTCUSDT -23.26U / AKEUSDT -11.85U / 牛来USDT -7.42U /
AVAXUSDT -2.10U / ... / BTRUSDT +26.61U.

## 3. HEMIUSDT 的完整证据链

2026-08-31 16:58:47 一笔 `BUY 1,779,986 HEMIUSDT @ 0.0165` = **29,369.77U 名义**,
37 分 38 秒后 (17:36:25) 全部平掉, 实现 -1654.18U + 手续费 -13.85U.

五条证据说明它不可能是 PA_Agent 下的:

1. `records/pending/` **全历史零个 HEMIUSDT 文件**(5797 个记录, 品种池 11 个, 不含它)
   -> 模型从未分析过它, 更不可能对它下单;
2. 名义 29,370U = 配置上限 5,000U 的 **5.9 倍**;
3. 该持仓杠杆 **10x**, 而配置是 20x;
4. 不在监控标的/白名单里 (当时是 BTC/ETH/SOL/ZEC/XRP, 全 15m);
5. `/fapi/v1/allOrders` 对该品种返回 **0 条** -> 没有经过执行层那条下单路径留下的痕迹.

同一账户 08-20 还有两笔小额 HEMIUSDT (9,085 / 6,056 数量级) —— 说明这个品种在 08 月就被人
在这个账户上手动玩过.

## 4. 结论

1. **账户亏损的 90% 是两笔违反名义上限的持仓**, 外加一批从未被策略分析过的品种.
   这不是策略的表现, 是**账户被污染**.
2. **策略自身在 30 天里是 -172.30U / 841 条腿**, 与 outcomes.csv 的 -167.84U 量级一致
   (差 2.7%) —— 这是账户口径与归因口径第一次互相印证. outcomes.csv 虽然只覆盖账户
   损益的 8%, 但它覆盖了**策略损益的绝大部分**.
3. 之前报告里"策略外 -1704.75U"这个数被两笔违规单主导, 不应该读成"策略外的交易在亏钱".

## 5. 建议

1. 把 `tools/account_contamination.py` 纳入例行检查: 任何"账户亏了多少"的结论, 先跑一遍
   污染诊断再引用.
2. 查那两笔是谁下的. 本地日志里**没有**痕迹(08-31 那天 `logs/` 无相关记录, 本地订单账本
   09-18 才开始记), 需要人工确认: 是不是手工在 testnet 网页端开的, 或者密钥被别处用过.
3. 在查清之前, 这个账户的账户级盈亏不能用来评价策略; 要评就评**策略范围**(第 2 节第一行).
4. 可考虑把污染汇总接进 `tools/outcome_merge.py` 的覆盖率报告, 让"账户真相"自带
   "其中多少不可能来自策略"这一行.

## 7. 例行接线: 污染汇总进 outcome_merge

纯判据抽到 `pa_agent/feedback/contamination.py`(`leg_notional` / `leg_net` /
`flag_reasons` / `contamination_summary`), `tools/account_contamination.py` 变成薄 CLI;
`build_audit_summary` / `merge_all` 新增可选 `analyzed_symbols` / `notional_ceiling`,
产出 `audit["contamination"]`. `tools/outcome_merge.py` 现在直接打印:

   污染诊断(上限 5000U): 策略可能 841 条 -172.30U | 不可能 1 条 -166.94U
     oversized_notional       1 条      -166.94U
   账户真相(income): 全账户 -1963.64U | 策略范围 -258.89U | 策略外 -1704.75U

**口径差异要知道**: `outcome_merge` 只抓它自己范围的品种(白名单 + trade_records CSV,
本次 10 个), 所以它的污染诊断只覆盖这些品种的成交腿 —— 本次只标出 BTCUSDT 那 1 笔
超标单. 要看全账户(含 HEMIUSDT / LTCUSDT / SKRUSDT 等策略外品种)必须直接跑
`tools/account_contamination.py`, 它会按 income 流水列出全部品种.

## 8. 取证: 两笔都在 2026-08-31, 无法从 API 定责

| | HEMIUSDT | BTCUSDT |
| --- | --- | --- |
| 开仓 | 08-31 16:58:47 | 08-31 19:28:37 |
| 平仓 | 08-31 17:36:25 | 08-31 20:42:42 |
| 数量 / 入场 | 1,779,986 @ 0.0165 | 0.2309 @ 78,507.1 |
| 名义 | 29,369.77U | 18,127.29U |
| 平仓 orderId | 252612000 | 28564724571 |
| `cid` | manual (未解析) | manual (未解析) |

两笔都在同一天、相隔约 2.5 小时, 都**没有** `pa-entry-` 前缀, 都超出名义上限.

能查到的与查不到的:

- **查得到**: 08-31 那天管道在跑(107 条 pending, 全是 15m, 5 个品种), 但品种池里没有
  HEMIUSDT; `records/pending/` 全历史零个 HEMIUSDT; 本地订单账本 09-18 才开, 覆盖不到
  08-31; 交易所 `allOrders` 对 HEMIUSDT 返回 0 条, 且整体只回溯到 09-15.
- **查不到**: 是谁下的. 币安 API 不暴露下单来源(网页端 / API key / 第三方程序); 本地
  `logs/` 里 08-31 没有任何相关记录; 两笔的 orderId 序列不同但无法据此推断客户端.

**所以只能给结论不能给定论**: 这两笔不可能是 PA_Agent 的决策管道产生的
(品种未分析 / 名义超上限), 但**是哪个客户端下的, 需要人工确认** —— 是不是手工在 testnet
网页端开的, 或者这套 API 密钥被别处用过.

## 9. 90 天窗口: 策略本身是 -7.18U, 账户亏损 99.7% 是污染

30 天窗口只看到 2 笔超标单, 容易被当成偶发. 拉到 90 天, 图案就清楚了:

| 分组 | 腿数 | 净额 |
| --- | --- | --- |
| 策略可能产生 | 1749 | **-7.18U** |
| 策略不可能产生 | **359** | **-2553.83U** |
| 账户合计 | 2108 | -2561.02U |

按判据: `oversized_notional` **8 条 -2286.85U**; `unanalyzed_symbol` 352 条 -1950.90U.

最大 5 笔:

| 品种 | 名义 | 净额 | 判据 |
| --- | --- | --- | --- |
| HEMIUSDT | 29,369.77U | -1683.91U | 未分析 + 超标 5.9x |
| BTCUSDT | 24,736.26U | -323.21U | 超标 4.9x |
| BTCUSDT | 25,733.54U | -197.66U | 超标 5.1x |
| BTCUSDT | 18,127.29U | -166.94U | 超标 3.6x |
| COLLECTUSDT | 1,058.25U | -54.70U | 未分析 |

策略外腿的品种面也说明问题: MAGMAUSDT 23 条 / COLLECTUSDT 6 条 / BOMEUSDT 20 条 /
BEATUSDT 38 条 / **BCHUSDT 183 条** / ONGUSDT 9 条 —— 管道从没碰过这些品种, 且
BCHUSDT 183 条的高频痕迹与管道的 5-10 品种 / 30m 节奏完全不同.

**两条结论, 都比 30 天窗口更强**:

1. **策略自己 90 天是 -7.18U / 1749 条腿 —— 基本走平.** 这与本会话其它几层证据
   (影子回放的 ≈0.00R、因子审计全线无信号) 完全一致: 扣掉成本后没有边际.
2. **账户那 -2561U 不是策略的**: 8 笔超标单占 89%, 加 352 条策略外腿. 而且这不是
   一次性事故 —— 4 笔 BTCUSDT 超标单 + 183 条 BCHUSDT 说明**这个账户上持续在跑另一套
   交易**, 不是手工偶发.

所以第 8 节"两笔都在 08-31"应理解为: 那是 30 天窗口的切片; 真实图案是另一套系统长期
在这个账户上交易, 且它有多次突破 5,000U 名义上限的大额下单.
