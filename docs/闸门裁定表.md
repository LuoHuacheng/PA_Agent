## 3. 裁定规则（照抄执行，不自行发挥）

| 观察到 | 裁定 |
|---|---|
| 区间**上界 < 0**（全负）且实盘**已开**该闸门 | ✅ 保留（闸门方向正确，是"关掉它"变差） |
| 区间**上界 < 0** 且实盘**未开** | ⚠️ 可开，但需 T6 的样本外复核后才动 |

| 区间**跨 0** | ❌ 证据不足 → **不动**（哪怕点估计很漂亮） |
