## 5. 稳健性检查（2026-09-18，对唯一 PASS 配方）

n=14 的 PASS 只是一次自助重采样的结果。用 `scripts/check_recipe_robustness.py` 做三重检验
（权威样本 `logs/shadow_rows_baseline45.csv`）：

| 检验 | 结果 | 判定 |
|---|---|---|
| 换种子 seed 1..20 | 下界 **+0.96 ~ +1.01**，20/20 同向 | 不是蒙特卡洛噪声 |
| 加大重采样 iters=100000 | 90%CI **[+0.99, +4.89]** | 同上 |
| 逐笔刀切（去掉任一笔） | **14/14 仍 PASS** | 无单笔独撑 |
| 收益集中度 | 前三笔 +9.17/+7.20/+6.95 = **+23.32U，占净额 56%** | 偏集中，但非孤笔 |
| 分布 | 盈 9 笔 +53.45U / 亏 5 笔 −11.85U（胜率 64%） | — |

**结论：PASS 对蒙特卡洛噪声与单笔剔除都稳。**

> ⚠️ **但这不等于「发现了可靠配方」**。刀切只检验「去掉一笔」，**消除不了选择效应**：
> 这个配方是从 13+ 个候选里、在同一批 45 笔上挑出来的（多重比较）。这正是第 0 节禁令 2
> 要求「选配方用前 38 天、报告用后 7 天」的原因，也是 T6 的实盘 R2 才是真正检验的原因。
> 一句话：稳健性检查排除了「手气差」，**没有排除「挑出来的」**。

## 6. 复现须知：`logs/shadow_rows.csv` 是草稿文件

它**每次 `--replay` 都会被覆盖**。T2 的表出自**默认参数**那一次（未改 `--time-stop-min`，默认 720）；
而 T5 的最后一轮用了 `--time-stop-min 100000`，把该文件换成了另一份样本——实测 **45 笔里有 5 笔净额不同**，
配方「做多+通道/区间」从 **+41.60U** 变成 **+38.85U**，CI 从 [+1.01,+4.90] 变成 [+0.70,+4.88]。

**权威样本**：`logs/shadow_rows_baseline45.csv`（2026-09-18 用默认命令重跑后存档）。
复跑 T2 表的**正确顺序**：

```bash
.venv/bin/python tools/shadow_replay.py --replay --days 45 \
  --min-stop-atr 1.5 --min-stop-pct 0.2 --timeout-min 30 \
  --trend-days 7 --trend-neutral 1.5 --variants      # 生成 logs/shadow_rows.csv
cp logs/shadow_rows.csv logs/shadow_rows_baseline45.csv
PYTHONPATH=. .venv/bin/python scripts/_t2_gate_ci.py --csv logs/shadow_rows_baseline45.csv
```

> `scripts/_t2_gate_ci.py` **默认就读 `logs/shadow_rows_baseline45.csv`**（不是草稿文件），
> 所以忘了加 `--csv` 也不会跑错样本；要临时比对别的样本才需要显式指定。
